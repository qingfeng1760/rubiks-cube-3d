# 3D 魔方

本地运行的 3D 魔方应用：**双击 `index.html` 就能玩**，无需安装、无需服务器、无需联网。
既能随手休闲把玩，也能像专业玩家一样速拧计时、记录成绩、看进步趋势。数据全部存在本机浏览器里。

## 快速开始

```bash
# 方式一：直接双击 index.html（推荐，完全离线可用）
# 方式二：本地静态服务器
node tests/serve.js          # 默认 8933 端口，打开 http://localhost:8933
```

> Three.js 已内置在 `js/vendor/three.min.js`，不依赖任何 CDN，断网也能正常打开。

## 功能

| 模块 | 说明 |
|---|---|
| **首页** | 继续上次的魔方（记住进度与步数）、新建一局、今日练习次数、最近成绩 |
| **三阶玩法** | 支持 **2×2 / 3×3 / 4×4 / 5×5** 四种阶数；拖动转层、拖动旋转视角、方向按钮转视角、打乱、复原、撤销、转层按钮、生成花样 |
| **速拧计时器** | 空格键 WCA 风格计时（按住预热、松手开表，防误触）、自动生成标准打乱公式、保存/放弃本把成绩 |
| **成绩统计** | 最佳 / 平均 / **ao5 / ao12**（速拧标准指标）、用时趋势图（最近 50 条）、成绩列表、清空成绩 |
| **设置** | 音效开关、转层动画速度、拖动灵敏度、魔方皮肤、数据导出 / 导入 / 清空 |

**花样图案**：棋盘格、竖条纹、横条纹、立方体套立方体（每个花样标注适用阶数）。
**皮肤**：经典、马卡龙、霓虹、莫兰迪（只改色调，面色家族与经典一致）。

## 数据与备份

全部数据（魔方进度、成绩、设置）存在浏览器 `localStorage`，刷新、关浏览器、重启电脑都不丢。

- **换浏览器 / 清浏览器数据会丢** —— 用设置里的「导出数据」备份成 JSON 文件兜底
- 「导入数据」会覆盖现有数据，导入前会提示确认
- 「清空全部数据」需要二次确认，清空后回到首次使用状态

## 运行测试

```bash
node tests/run.js              # 跑全部测试（当前 99 项）
node tests/run.js cube-core    # 只跑某个测试文件
node tests/serve.js            # 需要浏览器交互的验收用这个起服务
```

测试覆盖：魔方核心算法（打乱/复原/转层记法）、N 阶泛化、视角轨道旋转（独立实现四元数交叉验证）、
图案生成、皮肤数据、成绩统计（ao5/ao12/趋势）、数据读写层、静态验收、打包产物、清理工具安全边界。

## 打包成 Windows 桌面版（可选）

已配置 Tauri v2，可打包成独立 exe（需要 Rust 工具链 + MSVC 生成工具 + WebView2）。

```bash
node tools/build-exe.js            # 完整打包 → dist/3D魔方/3D魔方.exe
node tools/build-exe.js --check    # 快速校验工程是否可编译
node tools/build-exe.js --stage    # 只暂存网页资源与图标
node tools/make-icon.js            # 重新生成应用图标
node tools/window-check.ps1        # 启动打包后的 exe 并截屏自检（开发/验收用）
node tools/clean.js                # 清理编译缓存与构建产物（-h 查看各档）
```

## 目录结构

```
├─ index.html            入口（双击即用）
├─ css/                  样式
├─ js/
│  ├─ app.js             页面装配与模块切换
│  ├─ cube-core.js       魔方核心：面贴模型、转层、打乱、复原判定（2~5 阶泛化）
│  ├─ cube3d.js          Three.js 渲染、拖拽转层与视角轨道旋转
│  ├─ pattern-core.js    图案花样动作序列
│  ├─ skins.js           皮肤配色（纯数据）
│  ├─ stats-core.js      成绩统计（最佳/平均/ao5/ao12/趋势）
│  ├─ data-layer.js      统一数据读写层（业务代码不直接碰 localStorage）
│  └─ vendor/three.min.js  Three.js（内置，离线可运行）
├─ tests/                测试与本地静态服务器
├─ tools/                打包、图标、清理、窗口自检脚本
└─ src-tauri/            Tauri v2 桌面壳
```

**架构约定**：所有 localStorage 读写都必须经过 `js/data-layer.js`，业务代码不直接访问存储 —— 将来换成云同步只需改这一层。
